# 종합사고지수 (LTR Index) 테스트

언어(Language)·사고(Thinking)·추론(Reasoning)을 측정하는 온라인 인지능력 테스트입니다.
결과는 자체 지수(평균 100, 표준편차 15)와 IQ 환산치로 보여주며, 응답을 익명으로 쌓아 문항 분석과 규준 보정에 사용합니다.

> 본 테스트는 표준화된 전문 심리검사(지능검사)를 대체하지 않습니다.

## 검사 구성

빠른 검사(약 15분)와 정밀 검사(약 35분) 중 고를 수 있으며, 규준은 모드별로 따로 쌓습니다.

| 영역 | 유형 | 정밀 | 빠른 |
|---|---|---|---|
| 유동추론 (Gf) | 행렬 · 도형 시퀀스 · 도형 유추 · 다른 도형 찾기 · 도형 변환 기호 | 10 | 4 |
| 언어 (Gc) | 유추 · 범주화 · 유의어 · 반의어 · 문장 완성 | 8 | 4 |
| 수리 (Gq) | 수열 · 수 행렬 · 연산 기호 · 응용 계산 · 자료 해석 | 8 | 4 |
| 시공간 (Gv) | 블록 회전 · 종이 접어 구멍 뚫기 · 정육면체 전개도 · 조각 맞추기 | 8 | 4 |
| 작업기억 (Gwm) | 숫자 정순 · 역순 · 정렬 · 위치 기억 | 8 | 4 |
| 처리속도 (Gs) | 기호-숫자 변환 (90초) | 1블록 | – |

- 영역 경계: 유동추론은 도형만, 수리는 숫자만, 언어는 어휘·지식 기반으로 한정해 영역끼리 같은 능력을 묻지 않게 합니다.
- 한 검사지·한 영역 안에서 같은 유형은 최대 2번, 빠른 검사는 영역마다 서로 다른 유형 4개입니다.
- 슬롯(유형+난이도)마다 동형 문항을 6개 이상 두고 응시마다 하나를 무작위로 출제합니다. 4지선다 영역은 문항 풀이 30개 이상입니다.
- 구성표는 `core/schema.py`의 `BLUEPRINT`에 있습니다.

## 응시 흐름

- 영역마다 안내 화면 → 시작 → 문항. 4지선다 영역은 제한시간 안에서 이전/다음·번호로 자유롭게 이동하고 답을 바꿀 수 있습니다.
  시간이 끝나면 자동 제출되고, 직접 제출할 때 미응답 문항이 있으면 확인 창을 띄웁니다.
- 보기는 클릭 또는 키보드(1~4, A~D)로 고릅니다. 문제 그림은 이미지로 보여 줘 글자 복사가 되지 않습니다.
- 작업기억은 숫자/칸을 한 번만 보여 주고 키패드(또는 키보드)로 입력합니다. 자극은 응시마다 새로 정해집니다.
- 처리속도는 연습 3회 후 90초 동안 기호→숫자를 누르며, 점수는 (맞힌 수 − 틀린 수)입니다.
- 진행 상태는 DB에 저장되고 URL(`?s=세션ID`)에 세션이 남아, 새로고침해도 같은 문항·같은 남은 시간으로 이어집니다.
- 탭·창 이탈 횟수를 기록합니다. 문항별 응답과 응답 시간(ms)은 영역을 마칠 때 저장됩니다.

## 점수 산출 (`core/scoring.py`)

1. **문항 모수**: 응답 데이터가 쌓이기 전에는 문항별 예상 정답률로 가정 모수를 만든다.
   3모수 로지스틱 모형(4지선다 추측 0.2, 작업기억 0)에서 평균 능력(θ=0)의 정답률이 `expected_p`가 되도록 난이도 b를 잡는다.
   파일럿 데이터로 보정한 `irt_a/b/c`가 문항에 있으면 그 값을 쓴다.
2. **능력 추정**: 표준정규 사전분포를 둔 EAP(사후 평균)로 영역별 θ와 종합 θ(모든 문항을 하나의 일반 능력으로)를 추정하고,
   사후 표준편차를 표준오차로 쓴다. 처리속도는 (맞힌 수 − 틀린 수)를 가정 평균 40·표준편차 12로 표준화해 반영한다.
3. **지수 변환**: LTR Index = 100 + 15·z (40~160), 백분위 = Φ(z), 90% 신뢰구간 = 지수 ± 1.645 × 15 × 표준오차.
   LTR Index는 IQ와 같은 척도이므로 결과 화면에 IQ 척도 환산치로 함께 보여 준다.
4. **규준**: 같은 모드의 첫 응시가 100명을 넘으면 그 응시자들의 θ 분포로 다시 표준화한다 (그 전에는 가정 규준).
5. **강점·약점**: 영역 지수가 본인 영역 평균보다 8점 이상, 그리고 측정오차(1.28 × 표준오차)보다 크게 차이 날 때만 표시한다.

같은 개수를 맞혀도 쉬운 문항을 틀리고 어려운 문항만 맞힌 응답은 3모수 모형이 찍기로 보고 낮게 추정한다.

## 실행

```bash
pip install -r requirements-dev.txt
streamlit run streamlit_app.py
```

- 기본 저장소는 `data/iq_test.db`(SQLite)입니다.
- Supabase를 쓰려면 `.streamlit/secrets.toml.example`을 `secrets.toml`로 복사하고 `[connections.sql]`을 채웁니다.

## 문항 작성 규칙

- `slot`은 구성표의 슬롯 ID이고, 영역·유형·난이도는 슬롯에서 자동으로 채워집니다.
- `id`는 `<slot><동형 문자>` 형식 (예: `gc-04d`).
- `answer`는 보기 인덱스(0~3), `expected_p`는 예상 정답률(규준 데이터가 쌓이기 전 가정 규준에 사용).
- 문항을 고치면 `version`을 올립니다. 응답 로그에 버전이 함께 저장됩니다.
- 수리 문항은 `params.verify`에 정답 계산식을 적으면 검증 스크립트가 정답 보기와 일치하는지 확인합니다.

## 생성기

모든 생성기는 `seed`로 결정적이며(같은 문항 ID는 언제나 같은 그림·보기·정답 위치), 정답을 코드로 계산합니다.
동형 문항마다 다른 규칙 변형을 골라(`pick_variant`) 쌍둥이 문항이 겉모습만 바뀐 같은 문제가 되지 않게 합니다.

- **행렬·시퀀스·유추**: 보기는 각 속성의 정답 값이 4개 중 정확히 2개에 나오도록 균형 설계해 빈도로 정답을 짐작할 수 없습니다.
  유추는 A→B를 설명하는 다른 변환 조합이 C에 다른 답을 내면 버리고 다시 만듭니다.
- **다른 도형 찾기**: 다른 기준(모양·색·개수·방향·홀짝·꼭짓점 수)으로 보면 다른 도형이 튀는 경우를 버립니다.
- **수 행렬·연산 기호**: 제시된 예시를 다른 규칙으로도 설명할 수 있으면 버립니다. 오답은 다른 규칙을 적용한 값입니다.
- **블록 회전·조각 맞추기**: 회전 대칭이 없고 거울상과 구별되는 조각만 써서, 오답(거울상·한 칸 어긋남)은 돌려도 맞지 않습니다.
- **정육면체 전개도**: 전개도를 3차원으로 접어 각 면의 법선을 계산해 마주 보는 면을 구합니다.
- **종이 접기**: 접은 순서의 역순으로 대칭 구멍을 펼쳐 정답을 구하고, 오답은 축을 잘못 잡거나 한 번만 펼친 결과입니다.
