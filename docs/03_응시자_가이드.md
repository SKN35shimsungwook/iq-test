# 03. 응시자 가이드

## 1. 어떤 검사인가요

언어·사고·추론 능력을 6개 영역에서 측정해 **IQ와 같은 척도(평균 100, 표준편차 15)** 의 점수로 알려 주는
온라인 인지능력 테스트입니다. 이름이나 연락처는 받지 않습니다.

> 표준화된 전문 심리검사(지능검사)를 대체하지 않습니다. 진단·채용·진학 판단에 쓰지 마세요.

| 영역 | 측정하는 힘 | 문제 유형 |
|---|---|---|
| 유동추론 | 처음 보는 문제에서 규칙을 찾아내는 힘 | 행렬, 도형 시퀀스, 도형 유추, 다른 도형 찾기, 도형 변환 기호 |
| 언어 | 어휘와 낱말 사이의 관계를 이해하는 힘 | 유의어, 반의어, 유추, 범주화, 문장 완성 |
| 수리 | 수의 규칙을 찾고 계산으로 문제를 푸는 힘 | 수열, 수 행렬, 연산 기호, 응용 계산, 자료 해석 |
| 시공간 | 도형을 머릿속으로 돌리고 접고 맞춰 보는 힘 | 블록 회전, 종이 접어 구멍 뚫기, 정육면체 전개도, 조각 맞추기 |
| 작업기억 | 정보를 잠깐 붙잡아 두고 바꿔 다루는 힘 | 숫자 따라 하기(그대로·거꾸로·정렬), 위치 기억 |
| 처리속도 | 단순한 작업을 빠르고 정확하게 해내는 힘 | 기호를 숫자로 바꾸기 (정밀 검사만) |

## 2. 검사 방식 고르기

| | 빠른 검사 | 정밀 검사 |
|---|---|---|
| 시간 | 약 15분 | 약 35분 |
| 문항 | 영역마다 4문항 (쉬움·보통·어려움·매우 어려움 하나씩) | 영역마다 8문항 (유동추론 10) + 처리속도 90초 |
| 결과 | 종합 IQ 중심, 영역 점수는 참고용 | 영역별 강점·약점까지 |

처음이라면 빠른 검사로 시작해 2·3차 검증을 이어 하는 것도 좋습니다.

## 3. 진행 순서

```
1차 검증 ─→ 결과
   [2차 검증 하기] ─→ 1~2차 합산 결과
      [3차 검증 하기] ─→ 1~3차 합산 결과
         [심층검사 하기] ─→ 1~3차 + 심층검사 합산 결과
```

- **1·2·3차 검증**: 같은 구성의 검사를 **앞에서 나온 문제와 겹치지 않는 새 문제**로 다시 풉니다.
  여러 번 풀어 합칠수록 점수의 오차 범위가 좁아집니다. 2·3차는 하고 싶을 때만 하면 됩니다.
- **심층검사**: 3차를 마친 뒤 열립니다. 지금까지의 결과로 추정한 실력에 맞춰 문제를 **한 문제씩** 골라 냅니다.
  맞히면 더 어려운, 틀리면 더 쉬운 문제가 나오고, 점수가 충분히 정확해지면(오차 ±5점 안쪽) 다음 영역으로 넘어갑니다.
  영역당 3~6문항, 보통 20~30분입니다.

## 4. 화면 사용법

### 공통
- 영역마다 안내 화면이 먼저 나옵니다. **시작**을 누르면 그 영역의 제한시간이 흐릅니다.
- 위쪽 막대가 남은 시간입니다. 30초 남으면 빨간색으로 바뀌고, 시간이 끝나면 자동으로 다음 영역으로 넘어갑니다.

### 4지선다 (유동추론·언어·수리·시공간)
- 보기를 **클릭**하거나 키보드 **1~4** 또는 **A~D**로 고릅니다.
- 1·2·3차에서는 **이전/다음** 버튼과 아래 **번호**로 자유롭게 오가며 답을 바꿀 수 있습니다. 답한 문항에는 ✓가 붙습니다.
- 마지막 문항에서 **영역 제출**을 누르면 끝납니다. 답하지 않은 문항이 있으면 확인 창이 뜹니다.
- 심층검사에서는 답을 고르고 **확인**을 누르면 다음 문제가 정해지므로, **앞 문제로 돌아갈 수 없습니다**.

### 작업기억
- **시작**을 누르면 숫자(또는 칸)가 하나씩 나타납니다. **한 번만** 보여 주니 집중하세요. 메모는 하지 마세요.
- 숫자: 화면 키패드나 키보드 숫자로 입력하고 **확인**(또는 Enter). 지시에 따라 그대로 / 거꾸로 / 작은 수부터 입력합니다.
- 위치: 켜진 순서대로 칸을 누릅니다. 잘못 눌렀으면 **다시**로 지웁니다.

### 처리속도 (정밀 검사)
- 위 표에서 가운데 기호에 맞는 숫자를 누릅니다(키보드 1~9도 됨). 먼저 3번 연습하고 90초 본 검사를 합니다.
- 점수는 (맞힌 수 − 틀린 수)라서 빠르면서도 정확해야 합니다.

### 새로고침했을 때
- 주소창에 `?s=…`가 붙어 있어 새로고침해도 **같은 문항, 같은 남은 시간**으로 이어집니다.
- 단, 작업기억·처리속도 문제가 **보여지는 도중**에 새로고침하면 같은 문제를 다시 볼 수 없도록 그 문항은 **0점** 처리됩니다.

## 5. 결과 읽는 법

### 맨 위 (항상 보임)
| 항목 | 뜻 |
|---|---|
| **IQ (LTR Index)** | 지금까지 푼 모든 차수를 합친 점수. 평균 100, 표준편차 15 |
| **정확한 범위 (90%)** | 실제 IQ가 90% 확률로 들어 있는 범위. 차수를 더할수록 좁아짐 |
| **전체 응시자 중 위치** | 상위/하위 몇 %. "100명 중 약 몇 번째"로도 설명 |
| **수준** | 130 이상 매우 우수 · 120~129 우수 · 110~119 평균 상 · 90~109 평균 · 80~89 평균 하 · 70~79 낮음 · 69 이하 매우 낮음 |

### 탭
| 탭 | 볼 수 있는 것 |
|---|---|
| **1·2·3차 검증** | 그 차수의 IQ·범위(앞 차수 대비 변화), 맞힌 문항, 소요 시간, **난이도별 정답률**(어디서부터 막히는지), 영역별 결과, 3초 안에 고른 오답 안내, **문항별 정답과 해설** |
| **심층검사** | 1~3차와 합친 정밀 IQ, 문제를 풀 때마다 영역 점수 범위가 좁혀지는 그래프, 영역별 종료 이유, 해설 |
| **최종 결과** (처음 열리는 탭) | 분포에서 내 위치, 차수별·누적 점수 그래프, 일관성 판정, 영역별 최종 결과와 강점·약점, IQ 구간표, **결과 카드(PNG 저장)** |

### 해석할 때 알아 둘 것
- **범위를 함께 보세요.** "IQ 112, 범위 104~120"이면 112라고 단정하기보다 104~120 사이로 이해하는 게 맞습니다.
- **강점·약점**은 영역 점수 차이가 측정 오차보다 뚜렷할 때만 표시됩니다. 아무것도 없으면 영역 간 차이가 오차 안이라는 뜻입니다.
- **뒤 차수는 점수가 조금 오를 수 있습니다.** 문제 유형에 익숙해지는 연습 효과 때문입니다. 그래서 "상위 %" 기준은 1차 검증 응시자로만 만듭니다.
- **3초 안에 고른 오답**이 많다면 서둘러 찍은 답이 점수를 낮췄을 수 있습니다.
- 점수 기준이 "가정 기준"으로 표시되면 아직 실제 응시자가 적어 문항 난이도로 만든 기준을 쓰는 중입니다. 첫 응시자가 100명을 넘으면 실제 분포로 바뀝니다.

## 6. 자주 묻는 질문

**Q. 다시 풀면 같은 문제가 나오나요?**
같은 브라우저에서 2·3차·심층검사로 이어 풀 때는 앞에서 본 문제가 나오지 않습니다. 처음부터 새로 시작하면 무작위로 다시 뽑아서 일부가 겹칠 수 있습니다.

**Q. 처음부터 다시 했는데 점수가 왜 기준에 안 들어가나요?**
같은 브라우저에서 다시 본 검사는 연습 효과가 있어 전체 기준(규준) 계산에서 빠집니다. 내 결과는 정상적으로 나옵니다.

**Q. 휴대폰으로 해도 되나요?**
됩니다. 다만 도형 문제는 화면이 클수록 보기 편하고, 처리속도는 키보드가 있으면 유리합니다.

**Q. 답이 이상한 문제가 있어요.**
화면을 캡처해 운영자에게 보내 주세요. 생성 단계에서 "답이 두 개로 읽히는 문제"를 자동으로 걸러내지만, 빠진 경우가 있으면 고칩니다.
